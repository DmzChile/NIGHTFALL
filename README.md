# NIGHTFALL · Alpha 0.3

PC 키보드·마우스용 1인칭 3D 샌드박스 생존 웹게임. 첫날 빈손으로 가지·돌·풀을 모아 제작대를 설치하고 도구를 만든 뒤 밤의 몬스터를 견딘다.

## 실행

PC 키보드·마우스용이며 Node.js 22.13 이상과 pnpm이 필요하다.

```sh
git clone https://github.com/DmzChile/NIGHTFALL.git
cd NIGHTFALL
pnpm install
pnpm dev
```

Windows에서는 Node.js 설치 후 `package.json`이 있는 폴더에서 명령 프롬프트를 연다. pnpm이 없다면 `npm install -g pnpm@11.25.0`으로 설치한다. Vinext CLI 파일을 찾지 못하면 개발 의존성을 포함하는 `pnpm install --prod=false`가 성공하는지 먼저 확인한다.

개발 서버가 출력하는 로컬 주소(기본 `http://localhost:5173`)를 브라우저에서 연다. `새로운 섬 → 섬에 들어가기 → 계속하기`로 시작한다. 별도 게임 서버나 API 키는 필요 없다.

WASD 이동, 마우스 시점, E 채집·시설·아이템 회수, 좌클릭 공격, Tab 인벤토리·제작, M 지도, Esc 저장 메뉴. 제작대를 퀵슬롯에 넣고 빈 지면을 향해 E를 누르면 설치된다.

초기 Alpha 0.1 배포: https://nightfall-survival.gosaneo396.chatgpt.site (소유자 전용 접근). 이번 Alpha 0.3은 GitHub 소스 업데이트다. 소스의 `.openai/hosting.json`은 기존 Sites 프로젝트를 식별한다. GitHub 업로드 자체가 게임을 자동 배포하지는 않는다. 전체 기획은 `DESIGN.txt`에 보존했다.

## 이번 버전에 연결한 기능

- 시드 기반 1,024m 지형, 6개 지상 지역, 근처 자원 렌더링.
- 1인칭 이동·점프·질주·회피, 포인터 잠금, 메뉴와 숨긴 탭의 시간 정지.
- 허기·스태미나·체력, 채집 도구 단계와 내구도, 인벤토리·퀵슬롯.
- 일반 밤 적 12종과 소·양·새, 투사체·Tier·밤 계획·전리품.
- 돌→철→강철→미스릴 장비, 제작 시설과 예약된 제련·조리 작업.
- 시설 배치, 상자, 모닥불, 벽, 침낭과 일반/영구 사망.
- 기초 농사·낚시·덫, 치유/도전 토템, 수호자 제단과 봉인 조각 목표.
- IndexedDB 원자적 전체 스냅샷 저장, 30초 자동 저장, 3세대 보존, 손상 복구 안내, 다중 탭 잠금/세대 충돌 거부.
- SHA-256 백업 파일 내보내기·검증·복사 가져오기, 용량/입력 오류 안내.

## Alpha 0.2에서 추가한 기능

- **제작법 해금:** 처음 소지한 재료를 기록하고 모든 입력 재료를 발견한 제작법을 영구 해금한다. 손 제작과 돌 도구는 처음부터 공개하며 잠긴 제작법에 미발견 재료를 표시한다. 시설과 실제 재료도 필요하다.
- **정면 방어:** 방패로 정면 100도 직접 피해를 70% 줄인다. 성공마다 스태미나 12·내구도 1을 소비하고 스태미나가 부족하면 방어 실패 및 0.6초 경직을 적용한다. 공격 직후 0.25초, 활/지팡이 사용 중, 측후방 공격과 독 피해는 막지 않는다.
- **상태이상:** 독 화살은 5초간 초당 피해 2, 불꽃 지팡이는 4초간 초당 화상 피해 3을 준다. 같은 효과는 지속시간만 갱신한다. 보스 지속 피해는 절반으로 계산한 뒤 정수 반올림하고 둔화는 10%로 제한한다. Ember는 화상 면역이다. 해독제는 독 제거와 10초 독 저항을 제공한다.
- **낚시:** 중심에서 420m 이상 떨어진 해안에서 낚싯대를 들고 좌클릭한 뒤 7초 기다린다. 시작 시 성공률 70%를 판정해 저장한다. 일시정지 중에는 진행하지 않고 재접속 시 남은 시간부터 이어진다. 시작점에서 1m 넘는 이동, 점프·피격·장비 교체·낚싯대 보관 시 취소된다. 배낭이 가득 차면 생선을 바닥에 놓는다.
- **Archer 드랍:** 생성 때 부서진 활 80% 또는 내구도 45/180의 기본 활 20%를 결정한다. 부서진 활은 제작대에서 통나무 3+밧줄 2로 복원하거나 손 제작으로 통나무 1로 분해한다. 내구도 45 이하의 기본 활 수리는 제작대에서 통나무 2+밧줄 1을 소비해 내구도 45를 회복한다. 추가 Tier 재료 보상도 유지한다.
- **지역 적:** 밤 계획과 별도로 위험 지역에 적이 배회한다. HUD와 지역 발견 안내에 위험 Tier를 표시한다. 지역 진입 후 최소 12초, 플레이어와 28~40m 및 구조물에서 8m 이상 떨어져 생성된다. 지역별 2마리·전체 지역 적 6마리·전체 적 20마리 상한과 120초 재생성 간격을 적용한다. 180m 이상 멀어진 지역 적을 정리하며 시작점 100m 안에는 생성하지 않는다.

| 지역 | 종과 고정 Tier |
| --- | --- |
| 숲 | Wolf 2 / Spider 3 |
| 습지 | Slime 2 / Spider 3 |
| 바위 언덕 | Golem 4 / Bone Guard 3 |
| 화산 | Ember 4 / Golem 4 |
| 유적 | Bone Guard 3 / Hex Priest 6 |

지역 Tier는 날짜별 **밤 습격 상한과 별도**다. 기존 Alpha 0.1 저장본은 이전 제작법 접근을 유지하며 새 상태를 초기화한다. 발견 기록·낚시 작업·상태이상·장비 드랍·지역 스폰 시간은 저장과 파일 백업에 포함된다. Alpha 0.2 저장본은 최신 코드로 연다.

## Alpha 0.3 애니메이션

- **몬스터 관절:** 사람형의 걷기·호흡·공격 준비/타격/복귀, 네발 동물의 교차 걸음, 새의 날갯짓, 거미의 다리 움직임, Slime의 압축·팽창을 적용했다. 보스의 크기를 유지하며 이동과 방향 전환을 부드럽게 표시한다.
- **1인칭 동작:** 이동 중 손과 무기 흔들림, 공격·채집 휘두르기, 활의 발사 반동과 활줄 복귀, 지팡이 발사, 소비·배치 동작, 방패 들기/내리기, 낚시 대기 중 낚싯대 움직임을 연결했다. 시점에는 강제 흔들림을 추가하지 않았다.
- **반응과 효과:** 성공한 채집에 자원 흔들림과 파편, 피해를 받은 적에 피격 반응, 처치 시 0.45초의 쓰러짐·축소를 표시한다. 모닥불 불꽃과 바닥 전리품에도 움직임을 적용했다.
- **수명과 일시정지:** 파편은 최대 80개를 한 InstancedMesh로 그리며 처치 잔상은 최대 12개다. 잔상과 파편은 조준 대상에서 제외한다. 메뉴·탭 숨김으로 정지하면 연출 시간도 멈추고 월드 전환·종료 시 정리한다.

외부 모델이나 애니메이션 파일 없이 기존 Three.js 도형을 관절 그룹으로 나눈 절차적 연출이다. 피해량·공격 간격·자원 비용·전리품과 월드 난수는 유지한다. 연출 상태는 저장하지 않으며 기존 Alpha 0.1/0.2 저장본을 그대로 열 수 있다. 복구한 적은 저장된 공격 단계와 남은 시간에 맞춰 포즈를 표시하고 진행 중 낚시는 기존 저장 상태를 따른다.

## 기획 대비 남은 작업

이 버전은 완성 기획의 초기 구현이다. 동굴 별도 공간, 전체 토템 종류, 교역과 기상, 보스별 여러 단계 패턴·Wizard의 전체 스킬, Priest 강화 오라, 세부 사운드, 외부 모델의 키프레임과 무기/보스별 개별 애니메이션은 후속 작업이다. 장비는 몸통 슬롯 1개이며 낚시에는 미끼·수중 지형·줄 당기기 동작을 아직 적용하지 않았다. 벽/문 충돌은 구체로 근사하고 폭발 범위 피해에는 지형 가림을 적용하지 않았다.

저장은 초기 월드 크기에 맞춘 **전체 불변 스냅샷**으로 구현했다. 기획의 청크 revision/manifest 차이 저장·백그라운드 작업 분산과 버전 이관은 후속 확장이다. 저장 형식은 `formatVersion=1`, 생성기는 `generatorVersion=1`이다. 브라우저 데이터 삭제나 origin 변경에 대비해 파일 백업을 권장한다. 손상 백업 복구를 선택한 뒤 새 저장이 완료되면 3세대 보존 정책에 따라 옛 기록이 정리된다.

## 검증

```sh
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```

56개 테스트: 기존 게임·저장·충돌 24개, Alpha 0.2 기능 회귀 18개, 애니메이션·시각 이벤트 14개. 프레임 주기에 독립적인 이동 샘플, 포즈·관절 변환·보스 크기, 파편 상한/정지/해제, 성공한 명령의 이벤트, 연출 콜백 실패 시 게임 변경 유지, 연출의 저장/RNG 분리를 검사한다. 타입 검사·전체 lint·프로덕션 빌드를 함께 실행한다.

Chromium의 소프트웨어 WebGL 환경에서 새 월드·포인터 잠금·이동·공격·일시정지와 실제 관절 렌더링·방패·피격·처치 연출을 확인했다. 실제 노트북의 FPS, 장시간 플레이와 브라우저별 동작은 추가 검증이 필요하다.

저장 요청이 겹치면 대기 요청을 병합해 최신 상태를 한 번 더 저장한다. 저장 실패는 해당 요청 묶음을 종료하고 변경 상태를 유지한다. 다음 자동 저장 또는 메뉴의 저장으로 재시도할 수 있다. 복구 후보는 체크섬·스키마와 월드 ID/세대가 모두 일치해야 한다. 정상 후보가 없으면 기록을 유지하고 잠금을 해제한다.

`lib/game/data.ts`: 아이템·제작법·종·초기 밸런스.
`model.ts`: 직렬화 데이터·월드 생성·원자적 게임 변경.
`engine.ts`: 시뮬레이션·전투·제작·시간.
`scene.ts`: Three.js 렌더링·입력.
`animation.ts`: 프레임 보간·종별/무기별 포즈·이동 샘플.
`rig.ts`: 몬스터 관절 모델과 포즈 적용.
`effects.ts`: 수명이 제한된 파편 풀.
`visual-events.ts`: 게임 명령 결과를 렌더러에 전달하는 일회성 이벤트.
`storage.ts`: IndexedDB·저장 검증·백업.
`validation.ts`: 저장 스키마·제작 예약·전리품·참조 검증.
`save-queue.ts`: 동시 저장 요청 병합과 실패 처리.
`collision.ts`: 투사체 구간의 최초 충돌 계산.
`progression.ts`: 재료 발견·제작법 해금과 기존 월드 초기화.
`regions.ts`: 지역 적 종·Tier와 위험 안내.
`app.tsx`: 게임 메뉴·HUD·인벤토리·시설 UI.

`engine.ts`의 시뮬레이션은 시간/밤 스폰, 플레이어, 시설, 낚시, 지역 스폰, 적, 투사체 처리로 분리했다. 구조와 후속 작업의 경계는 [docs/architecture.md](docs/architecture.md)에 정리했다. 기존 정상 저장본의 형식과 IndexedDB 이름은 유지한다.

브라우저 WebMCP가 지원되면 현재 상태 읽기와 저장 도구를 등록한다. 미지원 브라우저에서도 게임은 같은 UI로 동작한다. WebMCP 지원은 이번 검증에 포함하지 않았다.
