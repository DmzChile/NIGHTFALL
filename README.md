# NIGHTFALL · Alpha 0.1

PC 키보드·마우스용 1인칭 3D 샌드박스 생존 웹게임. 첫날 빈손으로 가지·돌·풀을 모아 제작대를 설치하고 도구를 만든 뒤 밤의 몬스터를 견딘다.

## 실행

PC 키보드·마우스용이며 Node.js 22.13 이상과 pnpm이 필요하다.

```sh
git clone https://github.com/DmzChile/NIGHTFALL.git
cd NIGHTFALL
pnpm install
pnpm dev
```

개발 서버가 출력하는 로컬 주소(기본 `http://localhost:5173`)를 브라우저에서 연다. `새로운 섬 → 섬에 들어가기 → 계속하기`로 시작한다. 별도 게임 서버나 API 키는 필요 없다.

WASD 이동, 마우스 시점, E 채집·시설·아이템 회수, 좌클릭 공격, Tab 인벤토리·제작, M 지도, Esc 저장 메뉴. 제작대를 퀵슬롯에 넣고 빈 지면을 향해 E를 누르면 설치된다.

현재 배포: https://nightfall-survival.gosaneo396.chatgpt.site (소유자 전용 접근). 소스의 `.openai/hosting.json`은 기존 Sites 프로젝트를 식별한다. GitHub 업로드 자체가 게임을 자동 배포하지는 않는다. 전체 기획은 `DESIGN.txt`에 보존했다.

## 이번 버전에 연결한 기능

- 시드 기반 1,024m 지형, 6개 지상 지역, 근처 자원 렌더링.
- 1인칭 이동·점프·질주·회피, 포인터 잠금, 메뉴와 숨긴 탭의 시간 정지.
- 허기·스태미나·체력, 채집 도구 단계와 내구도, 인벤토리·퀵슬롯.
- 일반 밤 적 12종과 소·양·새, 투사체·Tier·밤 계획·전리품.
- 돌→철→강철→미스릴 장비, 제작 시설과 예약된 제련·조리 작업.
- 시설 배치, 상자, 모닥불, 벽, 침낭과 일반/영구 사망.
- 기초 농사·낚시·덫, 치유/도전 토템, 수호자 제단과 봉인 조각 목표.
- IndexedDB 원자적 전체 스냅샷 저장, 30초 자동 저장, 3세대 보존, 손상 복구 안내, 다중 탭 잠금/세대 충돌 거부.
- SHA-256 백업 파일 내보내기·검증·복사 가져오기, 용량/입력 오류 안내.

## 기획 대비 남은 작업

이 버전은 완성 기획의 초기 구현이다. 동굴 별도 공간, 전체 토템 종류, 교역과 기상, 보스별 여러 단계 패턴·Wizard의 모든 스킬, 세부 사운드와 애니메이션은 후속 작업이다. 방어는 현재 정면 각도 구분 없이 적용되며, 장비는 몸통 슬롯 1개로 단순화했다. 일부 상태이상과 낚시는 초기 모델이다. 지역 몬스터의 별도 상시 스폰, 일부 고유 드랍 장비 상태, 재료 발견 기반 제작법 해금은 확장해야 한다.

저장은 초기 월드 크기에 맞춘 **전체 불변 스냅샷**으로 구현했다. 기획의 청크 revision/manifest 차이 저장·백그라운드 작업 분산과 버전 이관은 후속 확장이다. 저장 형식은 `formatVersion=1`, 생성기는 `generatorVersion=1`이다. 브라우저 데이터 삭제나 origin 변경에 대비해 파일 백업을 권장한다. 손상 백업 복구를 선택한 뒤 새 저장이 완료되면 3세대 보존 정책에 따라 옛 기록이 정리된다.

## 검증

```sh
node node_modules/typescript/bin/tsc --noEmit
node --import tsx tests/game.test.ts
pnpm build
```

13개 검증: 시드 재현, 제작/이동 원자성, Tier 상한, 제련 복원, 중복 사망 보상, 일시정지, 체크섬, 저장 세대·충돌, 최신 손상 복구, 다중 탭 잠금, 아이템 검증. UI/3D 실제 브라우저 플레이와 기기별 FPS 검증은 별도 진행해야 한다.

`lib/game/data.ts`: 아이템·제작법·종·초기 밸런스.
`model.ts`: 직렬화 데이터·월드 생성·원자적 게임 변경.
`engine.ts`: 시뮬레이션·전투·제작·시간.
`scene.ts`: Three.js 렌더링·입력.
`storage.ts`: IndexedDB·저장 검증·백업.
`app.tsx`: 게임 메뉴·HUD·인벤토리·시설 UI.

브라우저 WebMCP가 지원되면 현재 상태 읽기와 저장 도구를 등록한다. 미지원 브라우저에서도 게임은 같은 UI로 동작한다. 이 환경에서는 WebMCP 및 실제 브라우저 QA가 검증되지 않았다.
