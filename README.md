# NIGHTFALL · Alpha 0.53

PC 키보드·마우스용 1인칭 3D 샌드박스 웹게임. 생존에서는 첫날 빈손으로 가지·돌·풀을 모아 제작대를 설치하고 밤의 몬스터를 견딘다. 크리에이티브에서는 모든 아이템을 꺼내 자유롭게 건축하고 비행할 수 있다.

## 실행

PC 키보드·마우스용이며 Node.js 22.13 이상과 pnpm이 필요하다.

```sh
git clone https://github.com/DmzChile/NIGHTFALL.git
cd NIGHTFALL
pnpm install
pnpm dev
```

Windows에서는 Node.js 설치 후 `package.json`이 있는 폴더에서 명령 프롬프트를 연다. pnpm이 없다면 `npm install -g pnpm@11.25.0`으로 설치한다. Vinext CLI 파일을 찾지 못하면 개발 의존성을 포함하는 `pnpm install --prod=false`가 성공하는지 먼저 확인한다.

개발 서버가 출력하는 로컬 주소(기본 `http://localhost:5173`)를 브라우저에서 연다. `새로운 섬 → 섬에 들어가기 → 계속하기`로 시작한다. 별도 게임 서버나 API 키는 필요 없다.

WASD 이동, 마우스 시점, E 채집·시설·아이템 회수, 좌클릭 공격, Tab 인벤토리·제작, M 지도, Esc 저장 메뉴, / 명령어 콘솔. 제작대를 퀵슬롯에 넣고 빈 지면을 향해 E를 누르면 설치된다. 크리에이티브에서는 F 비행 전환, Space 상승, Ctrl 하강, R 바라보는 시설·자원 철거를 사용한다.

게임 배포 주소: https://nightfall-survival.gosaneo396.chatgpt.site (소유자 전용 접근). 소스의 `.openai/hosting.json`은 기존 Sites 프로젝트를 식별한다. GitHub 업로드 자체가 게임을 자동 배포하지는 않는다. 전체 기획은 `DESIGN.txt`에 보존했다.

## 이번 버전에 연결한 기능

- 고정된 섬 지형의 언덕·능선·해안, 시드 기반 자원 배치, 6개 지상 지역과 근처 자원 렌더링.
- 1인칭 이동·점프·질주·회피, 포인터 잠금, 메뉴와 숨긴 탭의 시간 정지.
- 허기·스태미나·체력, 채집 도구 단계와 내구도, 인벤토리·퀵슬롯.
- 일반 밤 적 12종과 소·양·새, 투사체·Tier·밤 계획·전리품.
- 돌→철→강철→미스릴 장비, 제작 시설과 예약된 제련·조리 작업.
- 시설 배치, 상자, 모닥불, 벽, 침낭과 일반/영구 사망.
- 기초 농사·낚시·덫, 치유/도전 토템, 수호자 제단과 봉인 조각 목표.
- IndexedDB 원자적 전체 스냅샷 저장, 30초 자동 저장, 3세대 보존, 손상 복구 안내, 다중 탭 잠금/세대 충돌 거부.
- SHA-256 백업 파일 내보내기·검증·복사 가져오기, 용량/입력 오류 안내.
- 크리에이티브 모드, 검색 가능한 전체 아이템 목록, 비행·철거·자원 무소모 건축과 11개 게임 명령어.

## Alpha 0.53 크리에이티브와 명령어

새로운 섬 화면에서 생존/크리에이티브를 선택한다. 기존 월드는 일시정지 메뉴 또는 `/gamemode creative`와 `/gamemode survival`로 전환한다. 선택한 난이도와 일반/영구 사망 규칙은 별도로 보존하며 생존으로 돌아가면 적용한다. 이전 저장본은 생존으로 열린다. 생존이 종료된 영구 사망 월드는 명령으로 되살릴 수 없다.

- **자유 제작·건축:** 전체 제작법을 즉시 사용할 수 있고 재료·시설·연료를 요구하지 않는다. 건축물·음식·물약·씨앗·미끼·탄약은 사용할 때 소모되지 않으며 장비 내구도와 지팡이 충전도 줄어들지 않는다. 기존 지형 경사와 건축 충돌 검사는 적용하며 크리에이티브 건축물은 500개까지 허용한다.
- **아이템과 생존:** Tab의 크리에이티브 탭에서 96종 아이템을 이름/ID·종류로 검색하여 1개 또는 최대 한 묶음을 지급한다. 가방 용량 검사를 유지하고 소지품 삭제와 `/clear`로 정리한다. 체력·허기·스태미나는 유지하고 피해·부정적 상태이상을 막는다. 자연 발생하는 적 습격은 멈추고 기존 적과 직접 소환한 적은 플레이어나 시설을 공격하지 않는다.
- **이동·철거:** F로 비행을 켜고 WASD 이동, Space 상승, Ctrl 하강, Shift 가속을 사용한다. 비행 중 지면 기준 높이는 0~120m이며 기존 섬 경계 안에서 이동한다. R은 가까이 바라보는 자원이나 아이템으로 설치한 시설을 철거한다. 철거한 자원은 재생하지 않으며 시설 안의 보관품·작업 예약 재료는 바닥 가방에 남긴다. 월드 토템과 제단은 철거 대상에서 제외한다.
- **콘솔:** / 또는 일시정지 메뉴의 명령어 버튼으로 연다. 입력 중 게임 시간이 멈춘다. Enter 실행, Tab 첫 제안 완성, ↑/↓ 입력 기록, Esc 게임 복귀를 지원한다. 예시 버튼은 입력창만 채우며 실행은 별도로 누른다. 입력 기록은 현재 게임 세션에만 유지한다.

| 명령어 | 동작 |
| --- | --- |
| `/help [command]` | 명령어 목록 또는 한 명령의 사용법 |
| `/gamemode creative\|survival` | 게임 모드 전환, `1`/`0`도 허용 |
| `/give <item> [amount]` | 기본 1개, 1~999개 지급. ID 또는 따옴표로 감싼 한글 이름 사용 |
| `/items [검색어]` | 아이템 이름과 ID 검색 |
| `/time set day\|noon\|dusk\|night\|dawn\|0–719` | 현재 날짜의 시각 변경, 제작·재생·사용 대기의 남은 시간 보존 |
| `/tp <x> <z>` | 빈 지면으로 이동, `~` 또는 `~10` 같은 상대 좌표 지원 |
| `/heal` | 체력·허기·스태미나와 상태 회복 |
| `/fly [on\|off]` | 크리에이티브 비행 전환 |
| `/spawn <monster> [tier] [count]` | 유효한 종/등급의 적·동물 1~10마리 소환, 전체 60마리까지 |
| `/clear [item]` | 특정 아이템 또는 전체 소지품 삭제 |
| `/save` | 현재 월드를 기존 저장 큐로 저장 |

예: `/give wood 99`, `/give "철 검" 1`, `/time set day`, `/tp ~10 ~`, `/spawn wolf 2 3`. 아이템 지급은 가방에 전량을 넣을 수 있을 때만 성공한다. 명령은 허용된 동작과 인수만 해석하며 코드 실행을 지원하지 않는다. 모드와 비행 여부는 스냅샷·백업에, 모드는 월드 목록에 저장한다.

## Alpha 0.2에서 추가한 기능

- **제작법 해금:** 처음 소지한 재료를 기록하고 모든 입력 재료를 발견한 제작법을 영구 해금한다. 손 제작과 돌 도구는 처음부터 공개하며 잠긴 제작법에 미발견 재료를 표시한다. 시설과 실제 재료도 필요하다.
- **정면 방어:** 방패로 정면 100도 직접 피해를 70% 줄인다. 성공마다 스태미나 12·내구도 1을 소비하고 스태미나가 부족하면 방어 실패 및 0.6초 경직을 적용한다. 공격 직후 0.25초, 활/지팡이 사용 중, 측후방 공격과 독 피해는 막지 않는다.
- **상태이상:** 독 화살은 5초간 초당 피해 2, 불꽃 지팡이는 4초간 초당 화상 피해 3을 준다. 같은 효과는 지속시간만 갱신한다. 보스 지속 피해는 절반으로 계산한 뒤 정수 반올림하고 둔화는 10%로 제한한다. Ember는 화상 면역이다. 해독제는 독 제거와 10초 독 저항을 제공한다.
- **낚시:** 중심에서 420m 이상 떨어진 해안에서 낚싯대를 들고 좌클릭한 뒤 7초 기다린다. 시작 시 성공률 70%를 판정해 저장한다. 일시정지 중에는 진행하지 않고 재접속 시 남은 시간부터 이어진다. 시작점에서 1m 넘는 이동, 점프·피격·장비 교체·낚싯대 보관 시 취소된다. 배낭이 가득 차면 생선을 바닥에 놓는다.
- **Archer 드랍:** 생성 때 부서진 활 80% 또는 내구도 45/180의 기본 활 20%를 결정한다. 부서진 활은 제작대에서 통나무 3+밧줄 2로 복원하거나 손 제작으로 통나무 1로 분해한다. 내구도 45 이하의 기본 활 수리는 제작대에서 통나무 2+밧줄 1을 소비해 내구도 45를 회복한다. 추가 Tier 재료 보상도 유지한다.
- **지역 적:** 밤 계획과 별도로 위험 지역에 적이 배회한다. HUD와 지역 발견 안내에 위험 Tier를 표시한다. 처음 해당 지역의 위험 구역에 들어오면 12초 유예를 적용하며, 플레이어와 28~40m 및 구조물에서 8m 이상 떨어져 생성된다. 지역별 2마리·전체 지역 적 6마리·전체 적 20마리 상한과 120초 재생성 간격을 적용한다. 180m 이상 멀어진 지역 적을 정리하며 시작점 100m 안에는 생성하지 않는다.

| 지역 | 종과 고정 Tier |
| --- | --- |
| 숲 | Wolf 2 / Spider 3 |
| 습지 | Slime 2 / Spider 3 |
| 바위 언덕 | Golem 4 / Bone Guard 3 |
| 화산 | Ember 4 / Golem 4 |
| 유적 | Bone Guard 3 / Hex Priest 6 |

지역 Tier는 날짜별 **밤 습격 상한과 별도**다. 기존 Alpha 0.1 저장본은 이전 제작법 접근을 유지하며 새 상태를 초기화한다. 발견 기록·낚시 작업·상태이상·장비 드랍·지역 스폰 시간은 저장과 파일 백업에 포함된다. Alpha 0.2 저장본은 최신 코드로 연다.

## Alpha 0.3 애니메이션

- **몬스터 관절:** 사람형의 걷기·호흡·공격 준비/타격/복귀, 네발 동물의 교차 걸음, 새의 날갯짓, 거미의 다리 움직임, Slime의 압축·팽창을 적용했다. 보스의 크기를 유지하며 이동과 방향 전환을 부드럽게 표시한다.
- **1인칭 동작:** 이동 중 손과 무기 흔들림, 공격·채집 휘두르기, 활의 발사 반동과 활줄 복귀, 지팡이 발사, 소비·배치 동작, 방패 들기/내리기, 낚시 대기 중 낚싯대 움직임을 연결했다. 시점에는 강제 흔들림을 추가하지 않았다.
- **반응과 효과:** 성공한 채집에 자원 흔들림과 파편, 피해를 받은 적에 피격 반응, 처치 시 0.45초의 쓰러짐·축소를 표시한다. 모닥불 불꽃과 바닥 전리품에도 움직임을 적용했다.
- **수명과 일시정지:** 파편은 최대 80개를 한 InstancedMesh로 그리며 처치 잔상은 최대 12개다. 잔상과 파편은 조준 대상에서 제외한다. 메뉴·탭 숨김으로 정지하면 연출 시간도 멈추고 월드 전환·종료 시 정리한다.

외부 모델이나 애니메이션 파일 없이 기존 Three.js 도형을 관절 그룹으로 나눈 절차적 연출이다. 피해량·공격 간격·자원 비용·전리품과 월드 난수는 유지한다. 연출 상태는 저장하지 않으며 기존 Alpha 0.1/0.2 저장본을 그대로 열 수 있다. 복구한 적은 저장된 공격 단계와 남은 시간에 맞춰 포즈를 표시하고 진행 중 낚시는 기존 저장 상태를 따른다.

## Alpha 0.4 지형

- **언덕과 능선:** 시작점 주변은 완만한 평지로 두고 숲에 여러 언덕, 북쪽 바위 지역에 높은 능선, 화산 지역에 봉우리와 얕은 정상 분지, 유적에 고원을 추가했다. 해안은 모래 경사를 따라 수면 아래로 내려간다. 지역과 고도에 따라 지면 색을 바꾼다.
- **높이 일치:** 1,100m 지면 메시를 200×200칸으로 나눈다. 이동·카메라·자원·적·시설·투사체 판정은 화면에 그리는 삼각형과 같은 높이를 사용한다. 언덕을 오르면 시점도 지면을 따라 높아진다. 원거리 적은 플레이어의 지면 높이와 점프를 고려해 발사한다.
- **시설 배치:** X/Z 두 방향의 경사를 함께 확인한다. 경사 크기가 0.4를 넘는 지면에는 새 시설을 설치하지 않으며 거부 시 아이템을 소비하지 않는다. 기존 시설은 같은 X/Z 위치의 새 지면에 표시한다.
- **잔디와 손:** Alpha 0.3.1의 장식 잔디와 바람 셰이더를 제거했다. 제작 재료용 풀 채집 오브젝트는 유지한다. 화면 오른쪽 아래의 각진 팔·소매, 손목 기준 도구 휘두르기와 화면 비율에 따른 배치는 계속 사용한다.
- **기존 저장본:** `terrainVersion=2`를 기록한다. 필드가 없거나 1인 저장본은 불러올 때 한 번 이관한다. 플레이어·자원·시설·적의 X/Z, 아이템과 제작 작업을 유지하고 절대 Y를 저장한 투사체만 새 지면과 이전 지면의 높이 차이만큼 옮긴다. 체크섬을 먼저 검증한 뒤 복제본을 이관하며 원본 백업은 수정하지 않는다.

지형 모양은 모든 시드에서 같은 고정 섬이다. 시드는 기존 자원·몹 생성 난수에 사용한다. 굴착·지형 편집·경사에 따른 이동 속도와 낙하 피해는 아직 적용하지 않았다.

## Alpha 0.5 나무와 하늘

- **나무 상태:** 작은 나무·보통·대형·세계수로 나눈다. 소나무·참나무·자작나무·단풍나무와 두 색조 변형을 사용하고, 낙엽수의 `autumn` 플래그에 따라 붉은색·주황색·황금색 잎을 표시한다. 소나무는 상록수다. 크기와 수종은 생성 때 정해지며 자동 성장이나 계절 전환은 아직 없다.
- **내구도와 보상:** 일반 목재 나무는 아래 표를 따른다. 단단한 목재 나무는 내구도가 1.5배이고 목재 보상은 표 수량의 65%를 올림한다. 기존 철 도끼 이상 조건도 유지한다. 나무 채집에서 돌/철/강철/미스릴 도끼는 타격당 3/5/7/9, 빈손은 1을 깎는다. 타격마다 도구 내구도 1을 사용하고 기존 0.5초 채집 간격을 따른다. 조준 안내에 단계·수종·단풍·남은 내구도와 필요한 도구 단계를 표시한다.

| 단계 | 높이 | 일반 목재 내구도 | 일반 목재 보상 | 최소 도끼 단계 | 재생 시간 |
| --- | --- | --- | --- | --- | --- |
| 작은 나무 | 약 3.6m | 12 | 통나무 4 | 빈손 가능 | 4일 |
| 보통 | 약 6.5m | 24 | 통나무 8 | 빈손 가능 | 4일 |
| 대형 | 약 11m | 54 | 통나무 16 | 돌 도끼 1 | 5일 |
| 세계수 | 약 30m | 180 | 통나무 48 | 강철 도끼 3 | 10일 |

실제로 생성되는 세계수는 단단한 목재 나무여서 내구도 270·단단한 목재 32개를 적용하고 강철 도끼 이상을 요구한다.

- **숲 밀도:** 숲에 12m 격자의 높은 생성 확률을 적용하고 초원·습지는 낮은 확률로 추가한다. 확인한 새 월드 시드에서는 기존 약 90그루가 약 1,300그루로 늘었다. 세계수는 숲의 세 후보 구역에서 공간과 경사를 확인해 최대 3그루 배치하며 실제로는 단단한 목재를 준다. 시작점 38m 안의 공급 구역과 플레이어·시설·기존 자원·전리품 주변을 비운다. 화산·유적·바위 지역과 해안에는 추가 숲을 만들지 않는다.
- **렌더링과 충돌:** 줄기·가지·잎을 외형별 도형으로 합쳐 인스턴싱한다. 주변 150m의 나무를 8m 셀 이동 또는 활성 상태 변경 때 갱신한다. 인스턴스별 조준을 실제 자원 ID에 연결하여 채집·고갈·재생을 유지한다. 나무 크기에 따라 줄기 충돌 반경과 시설 배치 간격을 달리 적용한다.
- **태양과 달:** 별도 하늘 장면을 지형보다 먼저 그린다. 플레이어의 위치와 지형 높이가 바뀌어도 천체가 같은 방향의 배경에 남고, 시점 회전과 게임 시간에 따라 위치가 변한다. 태양의 약한 광륜, 밤의 달, 핏빛 달 색상을 표시한다. 언덕과 나무는 천체를 가리며 천체는 채집/공격 대상에 포함하지 않는다. 메뉴에서 시간이 멈추면 궤도도 멈춘다.
- **저장 호환:** 나무의 크기·수종·단풍·색조와 `forestVersion=1`을 저장한다. 기존 저장본은 불러올 때 외형과 추가 숲을 한 번 반영한다. 기존 나무의 ID·좌표와 남은 내구도 비율, 고갈·재생 시각을 유지하고 월드 RNG를 사용하지 않는다. 기존 시설·아이템·예약 작업도 유지한다. 이전 백업의 체크섬을 검증한 뒤 복제본을 갱신한다.

## Alpha 0.51 식별 반경·안개·구름

Alpha 0.50에서 0.01 올린 버전이며 패키지 버전은 `0.51.0`이다.

- **적 식별:** 아직 플레이어를 발견하지 못한 적은 대기하며 이동·공격·소환을 하지 않는다. 플레이어가 아래 식별 반경에 들어오면 기존 추적·공격 동작을 시작한다. 조준 안내에 미발견/추적 상태와 실제 식별 거리를 표시한다. 소·양·새는 기존 배회·피격 도주를 유지한다.

| 종 | 기본 식별 반경 |
| --- | --- |
| Slime | 22m |
| Stone Golem | 24m |
| Zombie | 28m |
| Bone Guard / Siege Brute | 30m |
| Venom Spider | 32m |
| Ember Spirit / Frost Wraith | 36m |
| Wizard / Hex Priest | 38m |
| Infected Archer | 40m |
| Night Wolf | 42m |
| 수호자·밤의 군주 | 60m |

- **추적과 도주:** 발견 뒤에는 식별 반경보다 12m 먼 거리까지 추적한다. 그 밖에서 3초 연속으로 떨어져 있으면 추적과 남은 공격 준비를 취소한다. 그 전에 돌아오면 이탈 타이머를 초기화한다. 직접 피해·둔화·독·화상·고통 효과를 맞으면 반경 밖에서도 반응하며 지속 피해만으로 이탈 타이머가 갱신되지는 않는다. 수호자는 기존 60m 전투 이탈 규칙을 유지한다. 식별은 수평 거리 기준이며 나무·벽·언덕 가림과 안개에 따른 AI 시야 제한은 아직 적용하지 않았다.
- **밤 습격:** 밤 계획으로 생성되는 일반 적은 식별 반경을 46m로 둔다. 기존 25~45m 생성 범위에서 플레이어를 발견해 밤 습격이 진행된다. 지역 적·도전 토템 적·소환물은 기본 종별 반경을 사용한다. 생성 수량·Tier·체력·피해·전리품은 유지한다.
- **안개:** 기존 거리 안개를 시간대·지역·고도에 따라 조절한다. 새벽과 습지는 짙고 높은 지형은 조금 옅다. 밤에는 하늘색과 함께 어두워지며 가까운 자원과 전투 대상은 잘 보이도록 밀도를 제한한다. 시간 변화와 하루 경계에서 연속적으로 바뀐다.
- **구름:** 하늘에 15개 구름 군집, 총 75개 둥근 도형을 한 InstancedMesh로 그린다. 게임 시간에 따라 천천히 이동하고 낮·밤 색을 바꾼다. 천체보다 앞에 있어 태양과 달을 가리고, 지형과 나무는 구름을 가린다. 플레이어의 이동과 지형 높이에 영향을 받지 않는 배경이며 채집·공격 대상에서 제외한다. 일시정지하면 이동도 멈춘다.
- **저장 호환:** 적의 `alerted`·`lostFor`를 스냅샷과 백업에 포함한다. 저장 후 이어도 남은 3초 이탈 시간이 이어진다. 필드가 없는 이전 저장본의 적은 기존 추적·공격 상태를 유지해 불러오며 원본 백업·ID·전리품·RNG를 바꾸지 않는다. 구름과 안개는 저장된 게임 시간에서 재현하므로 좌표를 따로 저장하거나 월드 RNG를 사용하지 않는다. 저장 형식과 IndexedDB 이름은 유지한다.

## Alpha 0.51 코드 점검 수정

버전은 `0.51.0`을 유지한다. 저장 체크섬을 기다리는 사이에 월드를 해제/전환/재획득했거나 기존 월드가 삭제되면 이전 저장을 취소한다. 잠금 상실 뒤에는 계속하기를 막으며 이전 엔진의 정리가 새 엔진의 잠금 콜백을 지우지 않는다. 저장 실패 시 파일 백업과 재시도를 유지하고 **저장 없이 메뉴로**를 선택할 수 있다. 확인 전에는 진행이 유지되고, 확인하면 마지막 저장본을 보존하고 메뉴로 돌아간다.

정상 방패의 내구도를 정확히 소비하고 회피/피격 무적으로 거부된 공격에는 독/둔화/저주를 적용하지 않는다. 회피의 줄기/광물/시설 충돌을 검사하며 사망 뒤 회복과 추가 시뮬레이션을 중단한다. 치명적인 음식 소비가 사망 가방에 반환되는 문제, Z=0 침낭 부활 좌표와 살아 있을 때의 부활, 노을 색의 갑작스러운 전환도 수정했다.

재현 조건·우선순위·검증 결과와 다음 구조 작업은 [코드 점검 기록](docs/code-audit.md)에 정리했다. 브라우저에서는 저장 실패 취소, SHA-256 파일 백업 검증, 저장 없이 종료 후 마지막 저장본 재접속, 권한 상실 뒤 재개 차단과 메뉴 복귀를 확인했다.

## Alpha 0.52 태양광·그림자·시각 효과

Alpha 0.51에서 0.01 올린 버전이며 패키지 버전은 `0.52.0`이다.

- **따뜻한 햇빛:** 태양 고도에 따라 크림색 직사광이 해질녘의 주황빛으로 바뀐다. 주변광을 낮추고 하늘에서 오는 푸른 빛과 지면의 갈색 반사광을 나눠 밝은 면과 그늘의 차이를 만든다. 태양이 지면 아래로 내려가면 같은 조명이 푸른 달빛으로 전환되며, 전환 지점에서는 직사광 강도가 0이어서 빛 방향이 갑자기 튀지 않는다. 핏빛 달에도 색상을 반영한다.
- **움직이는 그림자:** 나무 인스턴스·언덕·바위·시설·적/동물이 그림자를 드리우고 지형과 물이 받는다. 방향은 태양/달의 궤도를 따른다. 플레이어 앞쪽으로 조금 치우친 제한된 범위에 그림자 지도 하나를 사용하며, 조명 좌표의 texel 간격에 맞춰 범위를 움직여 흔들림을 줄인다. 손·도구·방패는 월드 그림자에서 제외하고, 모닥불과 토템의 점광원에는 별도 그림자 지도를 만들지 않는다.
- **하늘과 빛 번짐:** 지평선의 안개색에서 높은 하늘의 푸른색으로 이어지는 그라데이션, 태양 방향의 따뜻한 산란, 넓어진 광륜과 해질녘 구름의 황금색을 적용한다. 별도 하늘 장면의 기존 깊이 처리로 언덕·나무·구름이 천체를 가리는 동작을 유지한다.
- **하늘 표현 조정:** 구름 군집을 12개에서 15개로 25% 늘렸다. 태양은 밝은 크림색 중심에서 따뜻한 가장자리로 이어지는 부드러운 원반이며, 두 겹의 지수 감쇠 광륜과 하늘의 산란이 자연스럽게 빛을 퍼뜨린다. 해질녘에는 광륜이 조금 넓어지고 지평선 아래에서는 서서히 사라진다. 별도 화면 후처리나 반사 패스는 추가하지 않는다.
- **물과 모닥불:** 수면 법선을 작은 파동으로 움직여 태양/달과 시설 조명의 반짝임을 만든다. 화면 반사나 추가 반사 카메라는 사용하지 않는다. 파동은 실제 월드 시간으로 계산하며 메뉴에서 멈추고 불러온 시각에서 이어진다. 모닥불 불꽃에 자체 발광을 적용한다.
- **시각 품질:** `Esc → 시각 품질`에서 아래 설정을 바로 바꾼다. 기본값은 보통이며 선택값은 해당 브라우저의 기기 설정에 저장한다. 낮음에서는 그림자와 물결을 끄고 따뜻한 조명·하늘·구름·안개를 유지한다. 품질을 바꿀 때 이전 그림자 GPU 자원을 해제한다. 일시정지 중 변동이 없으면 그림자 지도를 다시 그리지 않는다.

| 품질 | 최대 픽셀 배율 | 그림자 지도 | 그림자 범위 폭 | 물결 |
| --- | --- | --- | --- | --- |
| 낮음 | 1.0 | 없음 | — | 끄기 |
| 보통 | 1.25 | 1,024 × 1,024 | 88m | 켜기 |
| 높음 | 1.5 | 2,048 × 2,048 | 128m | 켜기 |

실제 픽셀 배율은 기기의 배율 이하이며 그림자 해상도는 GPU의 최대 텍스처 크기 이하로 제한한다. 원거리에는 기존 안개를 유지하며 섬 전체에 고해상도 그림자를 그리지 않는다. 저장 형식·피해 판정·채집 보상·월드 난수는 변경하지 않는다. UUID는 `randomUUID`가 없는 개발 주소에서도 `getRandomValues`로 같은 UUIDv4 형식을 생성한다. 저장 체크섬의 Web Crypto 기능은 HTTPS 또는 localhost 환경을 필요로 한다.

## 기획 대비 남은 작업

이 버전은 완성 기획의 초기 구현이다. 동굴 별도 공간, 전체 토템 종류, 교역과 비 등 추가 기상, 보스별 여러 단계 패턴·Wizard의 전체 스킬, Priest 강화 오라, 세부 사운드, 외부 모델의 키프레임과 무기/보스별 개별 애니메이션은 후속 작업이다. 장비는 몸통 슬롯 1개이며 낚시에는 미끼·수중 지형·줄 당기기 동작을 아직 적용하지 않았다. 벽/문 충돌은 구체로 근사하고 폭발 범위 피해에는 지형 가림을 적용하지 않았다.

저장은 초기 월드 크기에 맞춘 **전체 불변 스냅샷**으로 구현했다. 기획의 청크 revision/manifest 차이 저장·백그라운드 작업 분산은 후속 확장이다. 저장 형식은 `formatVersion=1`, 생성기는 `generatorVersion=1`, 지형은 `terrainVersion=2`, 숲은 `forestVersion=1`이다. 브라우저 데이터 삭제나 origin 변경에 대비해 파일 백업을 권장한다. 손상 백업 복구를 선택한 뒤 새 저장이 완료되면 3세대 보존 정책에 따라 옛 기록이 정리된다.

## 검증

Alpha 0.53은 기존 118개와 크리에이티브·명령어 15개를 합친 133개 테스트를 통과했다. 이전 저장의 기본 모드, IndexedDB 모드/비행 복원, 피해 면역·자원 무소모, 반복 건축, 비행 높이, 적의 비공격, 철거 시 보관품 보존, 원자적 지급, 잘못된 인수 거부, 생존 전환, 시간 변경의 대기 보존, 상대 이동, 소환, 삭제 참조 정리와 저장 실패를 검사한다. 브라우저에서는 실제 공용 컴포넌트와 엔진 입력을 연결한 임시 화면에서 아이템 검색·지급·삭제, 숫자 입력 중 퀵슬롯 보존, 명령 실행·자동 완성·입력 기록·/ 재진입을 확인했다. 640px 화면과 200% 글씨의 배치를 확인했으며 검증 화면은 배포 소스에서 제거했다. 이번 브라우저의 WebGL 제한으로 전체 3D 플레이는 검증하지 않았다.

```sh
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```

118개 테스트: 기존 게임·저장·충돌 24개, Alpha 0.2 기능 회귀 18개, 애니메이션·시각 이벤트 14개, 지형·호환성 8개, 나무/하늘 12개, 식별/안개/구름 21개, 코드 점검 회귀 15개, 조명/그림자/물과 UUID 호환 6개. 시작 지역 경사, 언덕·해안 높이, 실제 지면 삼각형 교차, 양방향 경사 배치 거부, 기존 저장/백업 이관의 1회 적용과 원본 보존, 고저차 조준, 언덕 이동과 일시정지를 검사한다. 나무/하늘 검사에는 시드 재현·밀도와 공급 구역, 이전 IndexedDB/백업 이관, 도끼 단계별 채집과 원자적 보상, 재생/충돌, 실제 인스턴스 조준·고갈·재생, 도형/자원 해제, 천체의 궤도와 배경 렌더 순서도 포함한다. 식별 검사에는 모든 적의 반경 경계, 밤 습격과 지역 적 차이, 추적 이탈/재발견, 마법/소환 대기, 피격 반응, 이전 백업/IndexedDB 호환과 이탈 타이머 복원도 포함한다. 안개 밀도·하루 경계, 구름의 배치/이동/일시정지·시간 재현·GPU 자원 해제를 검사한다. 위 명령으로 타입 검사·전체 lint·프로덕션 빌드를 확인할 수 있다.

Chromium의 소프트웨어 WebGL 환경에서 지형 80,000개 삼각형의 렌더링, 능선·화산·해안 시점, 카메라의 지면 높이, 자원·시설의 지면 배치, 이전 백업 이관과 새 월드 생성 화면을 확인했다. Alpha 0.5에서는 약 1,300그루의 월드, 혼합 단풍 숲·세계수, 인스턴스 채집/고갈/재생, 일시정지, 태양·달의 배경 표시와 플레이어 이동 시 방향 유지, 새 월드 생성 화면을 확인했다. 샘플 시점에서는 주변 약 300그루를 66~68개 외형 묶음으로 그렸다. 이전 버전에서는 포인터 잠금·이동·공격·일시정지와 관절/손 동작을 확인했다. Alpha 0.51에서는 60개 구름 도형, 새벽/낮/밤 안개와 구름 색, 일시정지/재개, 미발견 적의 대기/반경 진입/이탈, IndexedDB 복원 후 추적 해제, 피격 반응과 새 월드 생성 화면을 확인했다. 모든 WebGL 프로그램의 링크 성공과 콘솔 오류 없음을 확인했다. 실제 노트북의 FPS, 장시간 플레이와 브라우저별 동작은 추가 검증이 필요하다.

Alpha 0.52에서는 118개 테스트, 타입 검사와 프로덕션 빌드를 통과했다. Mesa OpenGL ES 3.2에서 실제 셰이더를 확장해 물결(그림자 켜기/끄기), 하늘과 태양 광륜의 4개 프로그램을 컴파일·링크했다. 이번 검증 브라우저는 WebGL 장치가 Disabled로 표시되어 실제 화면 확인과 FPS 측정을 완료하지 못했다. 따라서 노트북에서 낮/노을/밤, 품질 전환과 숲/해안의 시각 품질·성능을 확인해야 한다.

이후 구름/태양 표현 조정에서도 118개 테스트, 타입 검사와 프로덕션 빌드를 통과했다. 실제 하늘 도형·카메라 행렬·재질 파라미터를 사용해 Mesa OpenGL ES 3.2에서 하늘, 기본 재질, 태양 원반과 광륜의 4개 프로그램을 컴파일·링크하고 낮·노을·밤을 하늘만 렌더링하여 확인했다. 앞쪽 구름이 태양 원반과 광륜을 가리는 배치도 확인했다. 전체 게임의 브라우저 렌더링과 실제 기기의 FPS 검증은 여전히 별도다.

저장 요청이 겹치면 대기 요청을 병합해 최신 상태를 한 번 더 저장한다. 저장 실패는 해당 요청 묶음을 종료하고 변경 상태를 유지한다. 다음 자동 저장 또는 메뉴의 저장으로 재시도할 수 있다. 복구 후보는 체크섬·스키마와 월드 ID/세대가 모두 일치해야 한다. 정상 후보가 없으면 기록을 유지하고 잠금을 해제한다.

## 메뉴와 인벤토리 정보 표시

- 메인 메뉴와 월드 목록에 이름·생존 일수·난이도·사망 규칙·마지막 저장 시각을 구분해 표시한다. 부활 대기와 생존 종료 상태도 표시하며, 저장 목록은 3D 화면의 초기화와 독립적으로 읽는다. 새 월드 생성 시 선택한 사망 규칙의 결과를 설명한다.
- 일시정지 메뉴는 월드/지역·체력/허기/스태미나, 플레이, 저장, 화면 설정을 나누고 아직 저장하지 않은 변경을 명시한다. 메뉴 위에서 동작 결과 안내가 보이도록 알림의 표시 순서를 조정했다.
- 배낭은 사용 칸/남은 칸, 착용 방어구와 방어력, 선택한 퀵슬롯을 상단에 보여준다. 아이템 카드에 수량·종류·슬롯/착용 상태·내구도 막대·파손·지팡이 충전을 표시한다. 선택한 아이템의 이름·설명·공격력/간격/사거리·채집 단계·회복량과 동작은 옆의 상세 패널에 표시한다.
- 가방의 공간 확장은 휴대만으로 적용됨을 설명하고 잘못된 착용 안내를 제거했다. 물약/음식 사용 대기와 붕대의 안전 대기를 표시하며, 일시정지 중 대기 시간도 멈춘다는 안내를 제공한다. 수리는 최대 내구도를 넘지 않는 회복량과 필요한 시설을 표시한다.
- 제작 카드에 시설·시간과 재료별 보유/필요 수량을 표시한다. 부족한 재료에는 텍스트와 색을 함께 사용하고 버튼에 미해금/재료 부족의 이유를 표시한다.
- 메뉴의 Tab/Space 기본 키 동작을 보존해 버튼 사이를 이동하고 실행할 수 있다. 플레이 중의 이동/퀵슬롯/포인터 잠금 흐름과 저장 형식은 유지한다.

기존 118개 테스트를 통과했다. 브라우저에서 실제 `InventoryView`와 엔진 동작을 사용하는 검증 화면으로 선택·수리(내구도와 재료 수량)·물약 사용(수량과 대기 시간)·퀵슬롯 등록·Tab 탐색을 확인했다. 640px 너비와 기본 글씨의 200% 크기에서도 가로 넘침이 없고 상세 동작에 스크롤로 접근할 수 있음을 확인했다. 새 월드 메뉴의 사망 규칙 전환도 확인했다. 검증 화면은 배포 소스에서 제거했으며 이번 브라우저의 WebGL 제한으로 전체 3D 게임 흐름은 다시 검증하지 않았다.
