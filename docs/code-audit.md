## 검증

기존 97개 테스트가 통과하는 상태에서 회귀 조건을 추가해 수정 전 12개의 실패를 재현했다. 최종적으로 점검 회귀 15개를 포함한 **112개 테스트**, TypeScript 검사, 전체 ESLint 검사를 통과했다. 저장 검사는 실제 IndexedDB 트랜잭션을 모사하고 체크섬 완료를 제어해 해제·월드 전환·동일 월드 재획득·삭제 후 쓰기를 검사한다. 백업은 SHA-256 검증 후 복원하며 원본을 변경하지 않는다.

```sh
pnpm typecheck
pnpm test
pnpm lint
pnpm build
```

프로덕션 빌드와 Chromium WebGL 검증도 통과했다. 브라우저에서는 실제 메뉴의 저장 실패, 취소, 파일 백업 검증, 저장 없이 종료 후 이전 체크포인트 재접속, 잠금 상실 뒤 재개 차단과 메뉴 복귀를 확인했다. 시간 123초의 미저장 진행은 백업 파일로 복원했고, 저장 없이 종료 후 재접속은 세대 1·시간 0초의 마지막 체크포인트를 유지했다. 안개·구름·적 식별의 기존 브라우저 검사도 함께 통과했으며 WebGL 프로그램 링크 실패와 콘솔 오류는 없었다.

## 구조와 다음 점검 범위

직렬화 모델·검증·저장 큐·IndexedDB·게임 시뮬레이션·Three.js 렌더링의 경계는 유지했다. 저장 format/content/generator 버전과 지형/숲 버전, IndexedDB 이름, 기존 정상 백업은 변경하지 않는다. 잠금 상실 표시는 엔진 세션에만 존재하며 저장 데이터에 포함하지 않는다.

- `engine.ts`와 `app.tsx`에는 아직 여러 기능의 명령과 화면 분기가 모여 있다. 기능을 늘릴 때 전투·시설 명령과 메뉴/인벤토리 화면을 분리하는 것이 다음 구조 작업이다.
- GitHub Actions 워크플로가 없어 검사는 현재 로컬 명령으로 실행한다. 다음 개발 단계에서는 같은 검사 명령을 CI에 연결하는 것이 좋다.
- 고밀도 숲과 저장 스냅샷은 실제 노트북의 프레임 시간 및 긴 세션에서 별도 측정해야 한다. 이번 소프트웨어 WebGL 검증은 화면·기능 검증이다.
