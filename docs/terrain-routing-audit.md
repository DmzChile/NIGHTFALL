# UI 커밋 이후 THREE.Terrain 생성 경로 점검

2026-10-03, GitHub `main`의 `6d36c0d7d2c23421c571d67ed487029dd2e5f9af`를 기준으로 분석했다.

## 원인

| 커밋 | 확인한 내용 |
| --- | --- |
| `b9769f0` | THREE.Terrain 기반 버전 3 모듈과 의존성 도입 |
| `4b35ff5` | 메뉴 선택을 일반 문서 흐름으로 개선. 부모가 `3bd0d44`인 별도 코드 계열이며 이 시점의 전체 트리에는 `world/` 지형 모듈과 `three.terrain.js` 의존성이 없음 |
| `fed1dd3`, `6d36c0d` | 병합으로 버전 3을 복원하고 강·연못 지형을 버전 4로 분리. `TERRAIN_VERSION=4`를 `createWorld()`가 그대로 사용해 새 월드 및 메뉴 미리보기의 기본 생성 경로가 버전 4로 변경됨 |

UI CSS가 지면을 숨기거나 Three.js의 import가 실패한 문제가 아니다. UI 커밋은 지형 도입 이전 계열에서 만들어졌고, 최신 병합에서는 지형 코드가 돌아왔지만 기본 생성기가 달라졌다. 버전 4는 자체 value/ridged noise를 사용하여 버전 3의 `TerrainNS.Simplex()`·`TerrainNS.Smooth()`를 호출하지 않는다. 공통 메시 생성에서는 여전히 `TerrainNS.fromArray1D()`를 사용한다.

점검 시작 시 배포된 소스는 버전 3 도입 소스와 동일한 `0cbad55`로, GitHub 최신 UI·강·연못 변경과도 차이가 있었다. 이번 배포는 최신 GitHub 변경과 아래 수정 사항을 함께 반영한다.

## 수정

- 최신 지원 저장 버전 `TERRAIN_VERSION=4`와 새 월드 기본값 `DEFAULT_TERRAIN_VERSION=3`을 분리했다.
- `createWorld()`에 선택 가능한 버전 `3 | 4`를 추가했다. 기존 다섯 인수 호출은 버전 3을 생성하며 유효하지 않은 선택은 거부한다.
- 새 월드 메뉴에 **평원 · 산맥 · 계곡**(기본, 버전 3)과 **완만한 산 · 강 · 연못**(버전 4)을 추가하고 실제 생성 호출까지 연결했다. UI 개선 커밋의 details/summary 선택·Escape 닫기·포커스 복귀를 유지했다.
- `/terrain info` 또는 `/terrain`이 실행 중인 TerrainManager의 버전·생성기·격자·시드·높이·경사를 읽도록 했다. 저장·RNG·디버그 표시를 변경하지 않으며, 종료된 월드에서도 조회할 수 있다. 디버그 변경은 기존 권한 검사를 유지한다.
- 기존 버전 2·3·4의 생성 함수와 저장 이관을 바꾸지 않았다. 이어하기에 새 메뉴의 선택값을 적용하지 않는다. 버전 4를 버전 3으로 바꾸면 지형과 건축물이 어긋나므로 기존 저장은 그대로 유지한다.

## 생성 경로

새 월드 선택 → `createWorld(..., terrainVersion)` → `getTerrain(state)` → `TerrainManager`

| 저장된 버전 | 생성기 | 격자 | THREE.Terrain 사용 |
| --- | --- | --- | --- |
| 2 | 기존 고정 섬 | 200×200 | 공통 메시 높이맵 적용 |
| 3 (새 월드 기본) | `TerrainGenerator.ts` | 128×128 | Simplex 다섯 스케일 → 평원·산맥·계곡·절벽 shaping → 선택적 Smooth → 메시 높이맵 적용 |
| 4 (선택 옵션) | `NaturalTerrain.ts` | 200×200 | 자체 노이즈·물길 생성 후 공통 메시 높이맵 적용 |

플레이어·자원·나무·시설·동물·적·투사체는 기존 TerrainManager 높이·경사·보행·기초 API를 계속 사용한다. 기본 지형 생성은 새 월드 최초 생성 시에만 실행하며, 게임 루프의 geometry 재생성이나 매 프레임 Raycaster는 추가하지 않았다. 버전 3/4의 기존 해상도·캐시와 성능 특성도 유지한다.

## 검증

- 전체 166개 테스트(19개 suite) 통과. 변경 전 최신 `main`도 164개 테스트가 통과해 import 실패와 생성 경로 변경을 구분했다.
- 생존·크리에이티브·미리보기 기본 호출이 버전 3 높이맵·128×128 격자·32,768개 삼각형을 생성하는 회귀 테스트를 추가했다.
- 실제 라이브러리 함수를 계측한 Node 실행에서 기본 생성은 Simplex 5회·Smooth 1회·fromArray1D 1회, 강·연못 선택은 Simplex 0회·Smooth 0회·fromArray1D 1회를 호출했다.
- 기존 버전 4 테스트가 버전 4를 명시하도록 변경하여 물길·수심·마른 스폰·낚시·수면 교차 검증을 유지했다.
- 버전 2·3·4 저장/백업 왕복, 플레이어 이동·점프·경사 제한, 채집·인벤토리·제작·명령어 등 기존 회귀 테스트를 유지했다.
- 브라우저에서 기본 지형 표시, 강·연못 선택 후 설명 변경, 선택 목록 닫기 및 Escape 포커스 복귀를 확인했다.
- 검증용 브라우저는 WebGL 컨텍스트 생성에 실패했다. 실제 3D 화면·포인터 이동·GPU FPS는 이 환경에서 검증하지 못했으며, geometry 생성·삼각형 교차와 게임 로직은 Node 런타임 테스트로 검증했다.

타입 검사와 변경 파일 lint가 통과했다. 프로덕션 빌드는 배포 워크플로의 `build-site.mjs`로 수행하며, 성공한 소스와 산출물만 배포한다.
